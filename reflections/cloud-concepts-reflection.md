# Cloud Concepts Reflection

Cloud computing has become an important part of my daily life because many of the applications I use rely on cloud services. Three cloud services that I use regularly are **Google Drive**, **Facebook Messenger**, and **Canva**. These applications allow me to store files, communicate with others, and create presentations or graphic designs from any device with an internet connection.

Google Drive is an example of **Software as a Service (SaaS)** because it provides cloud-based storage and file management without requiring users to install or maintain the underlying infrastructure. It uses the **Public Cloud** deployment model since the service is available to anyone with a Google account. Facebook Messenger is also a **SaaS** application because it offers messaging and communication services over the internet. It also follows the **Public Cloud** deployment model because millions of users can access the platform through Meta's cloud infrastructure. Canva is another **SaaS** application because it provides online graphic design tools through a web browser or mobile app. Like the others, it uses the **Public Cloud** deployment model, making its services available to users around the world.

Version control is essential when working on cloud infrastructure because it records every change made to project files and configurations. This allows developers to review previous versions, restore files when needed, and avoid losing important work. Git and GitHub make collaboration easier by allowing multiple team members to work on the same project without overwriting each other's changes. Features such as branches, pull requests, and commit history help organize development and make it easier to review updates before they are merged into the main project.

Through this activity, I learned that cloud computing is more than just online storage. It supports many of the digital services I use every day, while GitHub provides an efficient way to manage projects, collaborate with others, and maintain accurate records of changes. These tools are valuable for both learning and professional software development.
